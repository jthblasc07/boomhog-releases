# Boomhog

Background music for your D&D game, played into your Discord voice channel.

Download the latest installer from **[Releases](https://github.com/jthblasc07/boomhog-releases/releases/latest)**
(`Boomhog-<version>-Setup.exe`). Each release lists what's new in that version.

Boomhog updates itself: when a new version is ready, **Restart to update** appears at the top of the app.

Help: boomhogmusic@gmail.com
